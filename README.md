# Laural's Haven - Gourmet Ordering

Static storefront hosted on GitHub Pages. No server required.

- Live site: https://andrewvijaykumar123.github.io/Laural-sHaven-UI/
- Admin console: https://andrewvijaykumar123.github.io/Laural-sHaven-UI-AdminConsole/

## How the two sites work together

Both sites exchange small messages through a public relay (ntfy.sh) using two topics, with browsers connected over Server-Sent Events (polling fallback).

- Orders are encrypted in the customer's browser (AES-GCM, key wrapped with RSA-OAEP) for the admin public key. Only the admin console can read them.
- Status changes, payment verification, sold-out items and open/closed state are signed by the admin (ECDSA P-256). The storefront ignores anything not signed.
- Totals are recomputed from the embedded menu; all user text is sanitised and escaped.
- If the relay is unreachable, orders wait in a retrying outbox.

Limits: the relay keeps messages about 12 hours and has fair-use rate limits (roughly 250 publishes per day per IP on the free tier). For high volume, move to a real backend.

## Files

- `index.html`, `styles.css`, `app.js` - storefront UI
- `core.js` - shared menu (85 items, 18 categories), crypto and relay layer (identical copy lives in the admin repo)
- `keys.js` - public keys (generated by the admin repo tool `tools/gen-keys.mjs`)

## Deploy

Push to `main`; the GitHub Actions workflow publishes the site.
